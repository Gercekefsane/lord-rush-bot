## 🤔 WhiteLabel Nedir?

WhiteLabel, kendi Discord ve Telegram bot tokenlarınızı kullanarak **tamamen size özel bir bot** oluşturmanıza olanak tanır. İttifak üyeleriniz SİZİN botunuzu görür, bizimkini değil.

| Özellik | Standart Bot | WhiteLabel Bot |
|---------|-------------|----------------|
| Bot Adı | Lord Rush Bot | **Özel adınız** |
| Bot Avatarı | Varsayılan logo | **Özel avatarınız** |
| Karşılama Mesajı | Varsayılan | **Tamamen özelleştirilebilir** |
| Marka | woscontrol.com | **İttifak markanız** |
| Veri İzolasyonu | Paylaşımlı | **Size özel alan** |
| Öncelikli Destek | Topluluk | **Direkt destek** |
